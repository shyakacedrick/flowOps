# Screenshots

This folder holds the screenshots referenced by the root [README](../../README.md).

Drop the following PNGs in here (any size works — 1600×900 looks best on GitHub):

| File | Where it appears |
|---|---|
| `hero.png` | Top of the README, full-width hero |
| `dashboard.png` | Owner dashboard — live KPIs, customer flow, AI insights |
| `queue.png` | Queue management — tickets, priority, optimistic updates |
| `analytics.png` | Customer flow analytics — demand, throughput, leakage |

## Capture tips

- Sign in to the demo workspace (`demo.owner@flowops.app` / `Demo123!`) so the screens look populated.
- Set your browser window to **1600 × 900** for crisp captures that fit the README columns.
- Use the app in **dark mode** to match the rest of the FlowOps brand.
- Crop tight on the actual UI — avoid browser chrome.
